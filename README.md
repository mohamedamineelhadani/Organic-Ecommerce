# Organic E-Commerce Store

A full-stack organic e-commerce platform built from scratch — custom PHP 8 backend (MVC + DAO, no framework) with a modern React 18 + Vite frontend, connected to a MySQL database.

---

## Tech Stack

**Frontend:** React 18, Vite, React Router, Context API, Axios, Lucide Icons, Vanilla CSS
**Backend:** PHP 8, MySQL, PDO, Custom Router, HMAC-SHA256 Auth
**Server:** Apache (XAMPP)

---

## Features

- **Authentication** — Register, login, bcrypt hashing, HMAC-signed tokens
- **Products** — Category filter, search, sort, detail page
- **Cart** — Backend-synced, add / update / remove, real-time badge
- **Checkout** — Multi-step flow, online + COD payment, live totals
- **Orders** — History, status tracking, expandable order cards
- **Contact & Newsletter** — Subscribe + message forms with validation
- **UI/UX** — Responsive, dark mode, toast notifications, animations
